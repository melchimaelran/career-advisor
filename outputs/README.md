# outputs/

Deux fichiers générés par le Strategist à chaque run :

- `report-YYYY-MM-DD.md` — rapport tracé (chaque affirmation pointe vers
  `knowledge/`), validé par le Critic avant diffusion.
- `analyse-modele-YYYY-MM-DD.md` — second avis basé sur le jugement général
  du modèle, complémentaire au rapport, non soumis à la traçabilité et non
  relu par le Critic. Toujours précédé d'un avertissement en tête de fichier.
